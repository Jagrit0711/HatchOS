# Asset Placeholders

This directory should contain:

## Required Assets

1. **icon.png** (1024x1024)
   - App icon for home screen
   - Should feature the shield emoji 🛡️ or custom design

2. **splash.png** (1242x2436)
   - Launch screen
   - Should show Hatch Wall branding

3. **adaptive-icon.png** (1024x1024)
   - Android adaptive icon
   - Foreground layer for Android 8.0+

4. **favicon.png** (48x48)
   - Web favicon
   - For Expo web builds

## Creating Assets

You can:

1. **Use online tools**:
   - [Canva](https://www.canva.com) - Free design tool
   - [AppIcon.co](https://appicon.co) - Generate all sizes

2. **Use AI generation**:
   - Generate images with "shield firewall protection student safety" as prompt
   - Resize to required dimensions

3. **Use placeholders**:
   - Expo will use default icons if these are missing
   - Not recommended for production

## Quick Solution

For now, the app will work with Expo's default assets. Create proper assets before distributing to students.

## Recommended Design

- **Primary Color**: #6c5ce7 (purple)
- **Secondary Color**: #00d2d3 (cyan)
- **Theme**: Dark (#1a1a2e background)
- **Icon**: Shield with "HW" or "🛡️" symbol
- **Style**: Modern, clean, trustworthy
